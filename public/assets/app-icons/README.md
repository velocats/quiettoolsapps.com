# Real app icons

Drop the real app icon PNG files here:

- `cast-your-line.png`
- `aroundthehouse.png`
- `mealcost.png`
- `tripquest.png`
- `fixlog.png`
- `homesteadkeeper.png`

The app directory references these originals or optimized WebP derivatives. Cast Your Line uses `cast-your-line.png`, sourced from https://castyourlineapp.com/assets/icon-180.png. Keep each referenced asset present; app cards do not automatically fall back to placeholders.

You can use `scripts/download-app-icons.py` to refresh the icon files from each app's published website assets.
