# Real app icons

Drop the real app icon PNG files here:

- `mealcost.png`
- `tripquest.png`
- `fixlog.png`
- `homesteadkeeper.png`

The site is already wired to use these files in the app cards. If one is missing, the browser falls back to the simple placeholder SVG in `public/assets/app-placeholders/`.

You can use `scripts/download-app-icons.py` to download the live App Store icons for MealCost, TripQuest, and FixLog. Homestead Keeper is coming soon, so add that app icon manually when you have the final asset.
