# Real app icons

Drop the real app icon PNG files here:

- `mealcost.png`
- `tripquest.png`
- `fixlog.png`
- `homesteadkeeper.png`

The site is wired to use these files in the app cards. If one is missing, the browser falls back to the simple placeholder SVG in `public/assets/app-placeholders/`.

You can use `scripts/download-app-icons.py` to refresh the icon files from each app's published website assets.
